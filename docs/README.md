# 文档地图

本目录只放**对外可读**的工程文档：架构、规范、实测结论、偏差登记。过程性记录（审计、
工单、阶段验收、事故复盘）统一收在 [`internal/`](internal/README.md)，读者按需进。

> 阅读顺序建议：`README.md`（仓库首页） → 本文 → [`架构设计.md`](架构设计.md) →
> [`P-01`~`P-03`](P-01-申请支付单耗时定位-2026-10-17.md) 实测报告 → [`已知偏差台账-2026-10-15.md`](已知偏差台账-2026-10-15.md)。
