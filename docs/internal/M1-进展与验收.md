## 六、踩坑记录（本轮）

1. **`mvn` 参数在 PowerShell 里不加引号会被拆**：`-Dmaven.repo.local=D:\Maven\repository` 必须写成 `"-Dmaven.repo.local=D:\Maven\repository"`。
2. **本地仓库必须配 settings.xml**：`D:\Maven\settings.xml` 里定义了 aliyun 镜像；不带 `-s` 时 Maven 只认 `central`，会报"artifact has not been downloaded from it before"。
3. **PATH 默认 JDK 是 25**：本工程必须显式用 `D:\develop\jdk11`，否则 Spring Boot 2.7 + Lombok 会出各种反射/编译错误。
4. **`llmall-item-service` 与遗留 `legacy-monolith` 的 artifactId 撞名**（课程项目遗留缺陷），已修复。
5. **直接用 javac 编中文注释的源文件必须加 `-encoding UTF-8`**，否则按 GBK 解码直接报"不可映射字符"。
6. **javac 的 `@argfile` 不能用来传超长 classpath**（会把每个 jar 当成独立参数），要么用一条引号包住的长行，要么只选必要 jar。
7. **Maven 必须带 `-s D:\Maven\settings.xml`**：不带时 Maven 只认 `central`，而本地 jar 的 `_remote.repositories` 记录来源于 `aliyunmaven`，离线模式下会误判为"未下载过"。
