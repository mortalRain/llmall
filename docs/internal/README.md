# 过程记录（internal）

这里放的是**开发过程留痕**，不是交付物：审计报告、治理工单、阶段验收、事故复盘、早期设计稿。
它们被保留下来是因为它们能回答「这个决定是什么时候、因为什么做下的」，
但读者**不需要**读它们才能理解本项目——对外文档见 [`../README.md`](../README.md)。

> 约定：这些文档按写作时间归档，内容反映**当时**的状态，不随代码演进回头改写。
> 与当前实现冲突时，以代码与[`../已知偏差台账-2026-10-15.md`](../已知偏差台账-2026-10-15.md)为准。
