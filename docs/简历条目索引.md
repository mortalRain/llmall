## 三、边界速查（被问到就要主动说，别等被戳穿）

| 话题 | 正确说法 | 出处 |
|---|---|---|
| QPS 能不能上生产 | 单机同测口径（JMeter 与被测同宿主），绝对值不对标生产，**只有同环境梯度可信** | `benchmark/README.md:32、311-324` |
| Feed 是不是推拉结合 | **纯推**；大 V 超阈值跳过推送 → 粉丝看不到，属已登记缺口 | `content/FollowServiceImpl.java:158-166`；台账 C-01 |
| Seata 现在开着吗 | **默认关**（实测 +259% 代价）；对照数据与回滚实证都有 | `docs/P-03-…md` §四、§七 |
| 评论举报/审核 | **写侧链路不存在**，只有显示侧过滤被固化成单测 | 台账 C-04（`:60`） |
| 单测覆盖率 | 5 个测试类；验证靠 selftest 34 用例 + E2E 34 断言，不是靠单测覆盖率 | 台账 `:130-131` |
| 有没有 CI | **没有远端流水线**，是本地一条命令 + 手工基线流程；闸门第 3 道是"按清单"校验 | `gates/README.md:401-404` |
| 前端 | 有**单文件零依赖演示台**（`frontend/index.html`），不是工程化前端 | `frontend/README.md:3` |
